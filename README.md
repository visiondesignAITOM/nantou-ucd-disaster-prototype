# 南投縣政府災害情資網｜UCD 優化互動原型

這是南投防災網的使用者中心設計（UCD）互動原型展示頁，部署用途是提供內部與受邀測試使用。

## 資料與狀態揭露

- 這不是南投縣政府正式網站、正式資訊架構或正式服務。
- 尚未經南投縣政府或其他機關核准、審閱或授權。
- 使用者測試尚未執行，不代表任何使用者測試已通過。
- 本頁沒有串接即時交通、氣象、災情或政府資料來源；頁面使用單一 HTML 內嵌資料。
- 部分內容取自真實紀錄，但全部凍結於 2026/07/11–07/21；處所電話、距離、容量、開設狀態與停班停課為合成值。
- 處所電話為原型佔位號碼，不保證可撥通。
- 頁面中的避難、路況、警戒與停班停課內容不可作為即時決策依據；緊急情況請依官方公告、警消、現場管制與 119 指示行動。
